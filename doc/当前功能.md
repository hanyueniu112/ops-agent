# 当前功能

本文记录 **OPS大脑** 此刻已经落地的能力，对应仓库里可运行的 Web Agent，而不是规划稿。产品目标是做成通用化 OPS Agent：先把本机执行、会话、技能、Dream 记忆、工具这些底座打牢。

## 1. 产品与界面

- 品牌名：OPS大脑；默认简体中文回复
- 纯白页面：白底、深色文字、浅灰分割线
- 左侧会话栏与右侧对话区相互独立滚动：侧栏钉在视口，对话区只滚中间正文，顶栏和输入框固定
- 空会话提供可点的任务建议（看工作区、列技能、立刻 Dream、写并运行示例脚本）

## 2. 账号与会话

- 需要登录。支持注册新账号；未登录会跳到 `/login`
- 每个对话一个 session，地址为 `/s/{sessionId}`
- **公共会话**：所有登录用户都能在侧栏看到并打开（只读，只有创建者能继续发消息、改类型、删除）
- **个人会话**：只有创建者能看到；别人拿 session id 也打不开
- 侧栏分「公共会话 / 我的会话」，可新建「个人任务」或「公共任务」，创建者可把会话在公共/个人之间切换
- 跳转框支持粘贴 session id 或完整 `/s/...` 链接；无权或没有的会话会提示，不会在别人浏览器里凭空建一份
- 顶栏可复制当前 session id
- 会话列表和正文存在服务器 SQLite：`data/ops.sqlite`（可用 `OPS_DATA_DIR` 改目录）
- 换浏览器、清掉本机缓存、重启 `npm run dev` 都不会丢会话，只要这个 sqlite 文件还在
- 正在生成的会话切到别的页面后仍在后台继续；侧栏显示「处理中」
- 忙碌会话的对话面板保持挂载，避免切走就 `stop()`
- 首次登录会尝试把旧版浏览器 localStorage 里的会话迁进自己的个人会话

## 3. 模型与接入

- **Cursor 账号（默认）**：本机 `@cursor/sdk` Agent，读取 `.env.local` 里的 `CURSOR_API_KEY`
- 也可在设置里改用 DeepSeek、OpenAI、Kimi，或自定义 OpenAI 兼容 `baseURL`
- 设置保存在本地；非 Cursor 预设且未填密钥时会提示打开设置
- Cursor 运行时按 session 复用 Agent（映射写在被忽略的 `.weave-agents.json`）
- 支持思考过程（reasoning）流式输出

## 4. 对话展示

一条助手回复的固定顺序：

1. **Think**：思考过程，默认折叠
2. **工具**：搜索文件、匹配文件、读写文件等调用，默认折叠成「工具 N 项」
3. **正文**：Markdown（GFM 表格、代码块、链接等）

进行中时 Think / 工具不只显示「进行中」文案，而会有可感知的动态：

- 三点跳动、底边扫光、折叠条呼吸
- Think 折叠条上刷出当前思考片段
- 工具条显示正在执行的工具名和路径，数量变化时有弹出动画
- 会话结束后动效停止，避免历史记录一直闪

每轮只要有正文，旁边就有 **导出 MD**：

- 用户消息、助手消息各自独立导出
- 只导出该轮正文，不含 Think 和工具轨迹
- 文件名形如 `你-第1轮.md`、`OPS大脑-第2轮.md`

## 5. 工作区工具

Agent 默认在项目内 `workspace/` 中动手，不直接改仓库其它目录。

| 工具 | 作用 |
| --- | --- |
| `list_dir` | 列出目录 |
| `read_file` / `write_file` | 读、写文本文件 |
| `search_files` | 工作区文本搜索 |
| `run_command` | 在工作区根目录执行一条命令 |
| `fetch_url` | 抓取网页可读文本 |
| `web_search` | 网络检索 |
| `now` | 当前本地时间 |
| `list_skills` 等 | 列出/读写/新建/删除技能；可指定分组 |
| `create_skill_group` / `delete_skill_group` | 新建或删除技能分组 |
| `read_memory` / `read_dreams` / `run_dream` | 读长期记忆、读梦境日记、立刻跑一轮 Dream |

走 Cursor 运行时，还会用上 Cursor 侧的文件、检索、终端、MCP 等工具；界面里会翻译成「读取文件」「匹配文件」「搜索文件」等中文标签。

## 6. 技能（Agent Skills）

技能是带 YAML frontmatter 的 `SKILL.md`，用来把规范和工作流交给 Agent。目录为 `{scope}/.cursor/skills/{分组}/{名称}/SKILL.md`。

- **项目技能**：`workspace/.cursor/skills/`
- **个人技能**：用户主目录 `.cursor/skills/`
- **内置分组**：`general`（通用）、`alert-analysis`（告警分析）、`request-call`（请求调用）、`log-stream`（日志流）
- 可在「技能」面板新建自定义分组；内置分组不能删，分组里还有技能时也不能删
- 页面「技能」面板：按分组列出、新建技能、新建分组、编辑、删除
- Agent 工具：`list_skills`、`read_skill`、`write_skill`、`create_skill`、`delete_skill`、`create_skill_group`、`delete_skill_group`
- 仓库示例：
  - `general/brief-zh`、`general/code-review`
  - `alert-analysis/alert-triage`
  - `request-call/http-retry`
  - `log-stream/log-correlate`
- 仍兼容旧的顶层 `{名称}/SKILL.md`，会显示在「通用」分组

## 7. Dream（记忆整理）

Hermes 风格三阶段，只扫描**公共会话**，避免把个人任务写进共享记忆。

1. **浅睡**：从近期公共会话抽出较长文本，按关键词、时效、重复次数打分
2. **REM**：把主题和候选写进 `workspace/.ops/DREAMS.md`
3. **深睡**：高分条目写入 `workspace/.ops/MEMORY.md`；之后对话会把记忆片段注入系统提示

触发方式：

- 界面侧栏 / 顶栏「Dream」→「立刻整理」
- Agent 工具 `run_dream`
- 后台调度：公共会话安静 30 分钟后，且距上次自动 Dream 超过 6 小时，自动跑一轮

## 8. API 与运行时

- `POST /api/auth`：登录、注册、退出；`GET /api/auth`：当前用户
- `GET/POST /api/sessions`、`GET/PATCH/DELETE /api/sessions/:id`：会话
- `POST /api/chat`：对话流。Cursor 预设走 Cursor Agent；否则走 AI SDK `streamText` + 本机工具。需登录，且只有会话创建者能发
- `GET/POST/PUT/PATCH/DELETE /api/skills`：技能与分组（需登录）
- `GET/POST /api/dream`：Dream 状态与立刻整理（需登录）
- `GET /api/status`：当前接入状态
- 对话最长可跑数分钟（`maxDuration = 300`）
- 外部模型路径下工具循环有步数上限；Cursor 路径由 Cursor Agent 自己调度工具

## 9. 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 用户、登录令牌、会话、正文、Dream 运行记录 | `data/ops.sqlite`（可用 `OPS_DATA_DIR`） |
| 模型设置 | 浏览器 `localStorage` |
| 工作区文件 | `workspace/` |
| 项目技能（按分组） | `workspace/.cursor/skills/{分组}/{名称}/` |
| 个人技能 | `~/.cursor/skills/` |
| 长期记忆 / Dream 日记 | `workspace/.ops/MEMORY.md`、`workspace/.ops/DREAMS.md` |
| Cursor Agent 与 session 的映射 | `.weave-agents.json`（Git 忽略） |
| 密钥 | `.env.local`（Git 忽略） |

SQLite 使用 WAL。不要把库放进 `.next/`。备份只要复制 `data/` 目录。
