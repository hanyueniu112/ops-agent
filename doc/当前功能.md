# 当前功能

本文记录 **OPS大脑** 此刻已经落地的能力，对应仓库里可运行的 Web Agent，而不是规划稿。产品目标是做成通用化 OPS Agent：先把本机执行、会话、技能、工具这些底座打牢。

## 1. 产品与界面

- 品牌名：OPS大脑；默认简体中文回复
- 纯白页面：白底、深色文字、浅灰分割线
- 左侧会话栏与右侧对话区相互独立滚动：侧栏钉在视口，对话区只滚中间正文，顶栏和输入框固定
- 空会话提供可点的任务建议（看工作区、列技能、写并运行示例脚本）

## 2. 会话

- 每个对话是一个 session，地址为 `/s/{sessionId}`
- 打开根路径 `/` 会跳到新的或已有会话
- 侧栏可新建任务、浏览历史、删除会话
- 跳转框支持粘贴 session id 或完整 `/s/...` 链接
- 顶栏可复制当前 session id
- 会话列表与消息缓存在浏览器 `localStorage`
- 切换会话不会丢掉历史；空消息不会覆盖已有存档
- 正在生成的会话切到别的页面后仍在后台继续；侧栏显示「处理中」
- 忙碌会话的对话面板保持挂载，避免切走就 `stop()`

## 3. 模型与接入

- **Cursor 账号（默认）**：本机 `@cursor/sdk` Agent，读取 `.env.local` 里的 `CURSOR_API_KEY`
- 也可在设置里改用 DeepSeek、OpenAI、Kimi，或自定义 OpenAI 兼容 `baseURL`
- 设置保存在本地；非 Cursor 预设且未填密钥时会提示打开设置
- Cursor 运行时按 session 复用 Agent（映射写在被忽略的 `.weave-agents.json`）
- 支持思考过程（reasoning）流式输出

## 4. 对话展示

一条助手回复的固定顺序：

1. **Think**：思考过程，默认折叠
2. **工具**：搜索文件、匹配文件、读写文件等调用，默认折叠成「工具 N 项」
3. **正文**：Markdown（GFM 表格、代码块、链接等）

进行中时 Think / 工具不只显示「进行中」文案，而会有可感知的动态：

- 三点跳动、底边扫光、折叠条呼吸
- Think 折叠条上刷出当前思考片段
- 工具条显示正在执行的工具名和路径，数量变化时有弹出动画
- 会话结束后动效停止，避免历史记录一直闪

每轮只要有正文，旁边就有 **导出 MD**：

- 用户消息、助手消息各自独立导出
- 只导出该轮正文，不含 Think 和工具轨迹
- 文件名形如 `你-第1轮.md`、`OPS大脑-第2轮.md`

## 5. 工作区工具

Agent 默认在项目内 `workspace/` 中动手，不直接改仓库其它目录。

| 工具 | 作用 |
| --- | --- |
| `list_dir` | 列出目录 |
| `read_file` / `write_file` | 读、写文本文件 |
| `search_files` | 工作区文本搜索 |
| `run_command` | 在工作区根目录执行一条命令 |
| `fetch_url` | 抓取网页可读文本 |
| `web_search` | 网络检索 |
| `now` | 当前本地时间 |

走 Cursor 运行时，还会用上 Cursor 侧的文件、检索、终端、MCP 等工具；界面里会翻译成「读取文件」「匹配文件」「搜索文件」等中文标签。

## 6. 技能（Agent Skills）

技能是带 YAML frontmatter 的 `SKILL.md`，用来把规范和工作流交给 Agent。

- **项目技能**：`workspace/.cursor/skills/`
- **个人技能**：用户主目录 `.cursor/skills/`
- 页面「技能」面板：列出、新建、编辑、删除
- Agent 工具：`list_skills`、`read_skill`、`write_skill`、`create_skill`、`delete_skill`
- 仓库里已带两个项目技能示例：`brief-zh`（回复尽量短）、`code-review`（代码审查口径）

## 7. API 与运行时

- `POST /api/chat`：对话流。Cursor 预设走 Cursor Agent；否则走 AI SDK `streamText` + 本机工具
- `GET/POST/PATCH/DELETE /api/skills`：技能的增删改查
- `GET /api/status`：当前接入状态
- 对话最长可跑数分钟（`maxDuration = 300`）
- 外部模型路径下工具循环有步数上限；Cursor 路径由 Cursor Agent 自己调度工具

## 8. 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 会话列表、每条消息 | 浏览器 `localStorage` |
| 模型设置 | 浏览器 `localStorage` |
| 工作区文件 | `workspace/` |
| 项目技能 | `workspace/.cursor/skills/` |
| 个人技能 | `~/.cursor/skills/` |
| Cursor Agent 与 session 的映射 | `.weave-agents.json`（Git 忽略） |
| 密钥 | `.env.local`（Git 忽略） |

没有独立账号系统，适合单人本机使用。

## 9. 尚未做成的（避免误认）

- 多人协作、云端同步会话
- 细粒度命令沙箱与审批流
- 与具体监控 / 工单 / CMDB 的开箱即用对接
- 移动端专用布局（窄屏会隐藏侧栏）

这些属于通用化 OPS Agent 的后续方向，不在当前版本承诺范围内。
