# alert-triage

## 何时使用
用户给出告警列表、告警风暴、重复告警，或要求判断优先级和可能根因时使用。

## 步骤
1. 按服务、实例、指纹归并，去掉同一根因的重复条目。
2. 标出影响面最大、正在恶化、以及刚出现的新告警。
3. 结合近期公共记忆和日志/调用线索，给出 1–3 个最可能根因，并写清还缺什么证据。
4. 给出下一步：该查哪段日志、打哪个接口、要不要扩容/回滚。不要编造没看到的指标。
