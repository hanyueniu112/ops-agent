# log-correlate

## 何时使用
用户提供日志片段、trace/request id、时间范围，或要求从日志里找异常传播路径时使用。

## 步骤
1. 抽出时间戳、级别、服务名、request/trace id。
2. 在工作区搜索同一 id 或同一时间窗的相邻日志。
3. 按时间排序，标出第一次错误和后续连锁反应。
4. 结论里写清证据行，缺文件就说明还要哪一类日志，不要补造日志内容。
