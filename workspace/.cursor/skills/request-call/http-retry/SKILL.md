# http-retry

## 何时使用
用户给出失败请求、超时、重试次数、上游 4xx/5xx，或要约定调用方式时使用。

## 步骤
1. 先确认方法、路径、状态码、耗时、是否幂等、重试了几次。
2. 区分客户端超时、网关、下游过载和业务拒绝。
3. 建议安全的重试：只对幂等读请求自动重试；写请求要有幂等键。
4. 需要时用工作区文件或 fetch_url 核对接口约定，不要臆造响应体。
